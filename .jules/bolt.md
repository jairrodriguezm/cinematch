## 2024-10-25 - React Component Re-render Bottleneck via Async State
**Learning:** In the `MovieDeck` component, fetching streaming providers occurred via an asynchronous `useEffect` hook which called `setProviders` and `setLoadingProviders`. This caused the large parent `MovieDeck` component (which renders animations, a rating slider, cast data, etc.) to re-render unnecessarily after mounting and again when data loaded.
**Action:** Always extract asynchronous data-fetching logic and its associated loading state into isolated, `React.memo`-wrapped child components (like `WatchProviders.tsx`). This localized state update ensures updates from loaded data do not bottleneck UI rendering of complex parent components.
